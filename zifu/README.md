# zifu（紫府）

> 交互平面底层容器宿主。纯前端标准化交互底座，全平台所有业务交互的承载层。

详细职责、边界、技术栈见 [`../设计文档.md`](../设计文档.md) 第一章「zifu（紫府）」。

## 当前状态

**规划中**。本目录为四模块重构后新建的工程位，尚未包含源码。

参考验证位于 [`../.poc/opensumi-web/`](../.poc/opensumi-web/)（前期调研产物，OpenSumi/CodeBlitz 容器已本地跑通）。

## 边界约束（摘自设计文档）

- 纯浏览器运行，**无** Node.js 运行时、无后端逻辑。
- 不直连 Agent 运行时，所有请求统一经太虚（taixu）网关转发。
- 不硬编码服务凭据。
- 仅承担容器渲染、插件生命周期管控、跨模块消息中转。
- 全局 command 命令通信总线：插件之间**仅**通过标准命令 ID 联动，禁止跨包直接导入。

## 与其它模块的接口

- **VSIX 来源**：从 [langhuan](../langhuan/) 拉取业务插件清单与版本。
- **流式 UI 通道**：与 [dongfu](../dongfu/) 通过 [taixu](../taixu/) 网关建立 SSE 长连接，由对话类 VSIX 处理 A2UI 流式 UI 渲染。
- **交互指令**：非对话类插件通过标准 command 转发，不直连 dongfu。
